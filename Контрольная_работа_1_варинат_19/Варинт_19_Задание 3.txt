Задание 3

Исходное выражение:
9y - 5(17 - y)

Упрощение выражения:
14y - 85

Исходный код программы:

#include <iostream>
using namespace std;

int main(){
	double y; //объявляем переменную для коэффицента y
	cout << " Упрощенный вид: 14y - 85 " << endl; //пояснение  для пользователя
	cout << " Введите значение y: "; //запрашиваем ввод коэффицента y
	cin >> y;
	double result = 14 * y - 85; //вычисляем значение по упрощенной формуле
	cout << "Результат вычисления:  " << result << endl;//выводим результат
	
	return 0; 
}

Описание кода:
- тип данных double используется для возможности ввода как целых, так и дробных чисел.
- в программе используется уже упрощенная формула (14 * y - 85), согласно требованиям задания.
- соблюдены принципы "чистого кода": понятные имена переменных, отступы, наличие комментариев  к каждому логическому блоку.
